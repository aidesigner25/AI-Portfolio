# Mike Seitz portfolio

This is a static site. The repository root contains index.html, style.css, script.js, and the assets directory; keep those together. Upload the contents of this folder to your GitHub repository, then configure GitHub Pages to publish from the branch and folder containing index.html. The site uses relative paths and does not require a build step or backend.

Edit index.html for content, style.css for presentation, and script.js for navigation and image-viewing behavior.
